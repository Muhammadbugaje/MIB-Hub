# Carry-over inventory (Stage 0)

This is Master Game Guide V3 §5 turned into a concrete list. Every item says where it is now in this repo, what we decided to do with it, and where it will go in the new monorepo (V2 §19.2).

The three decisions are:
- **As-is:** data or writing that is reused directly. It is converted to the new format, and its meaning is not changed.
- **Spec:** the old code is read as the requirements, then rebuilt on the new engine. No code is copied.
- **Left behind:** kept only in `legacy/fslg-classic` for the Classic build.

The short forms below stand for these paths:

| Short form | Path |
|---|---|
| `L/` | `legacy/fslg-classic/` |
| `L/js/` | `legacy/fslg-classic/static/js/games/` |
| `DL/` | `docs/legacy/` |
| `DP/` | `docs/plan/` |

**Naming change for every item.** The old game uses real place names (Samaru, ABU, Kwari Dam, and others). The new game is set at a fictional `{{UNI_NAME}}` in `{{TOWN}}`, so every carried string goes through tokens (V3 §8, Story Bible V2).
