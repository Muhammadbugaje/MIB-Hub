The short version

In every game: 1. on the title or character screen do the reveal move for that game (below). 2. The secret character appears; choose him and confirm. 3. Type the secret code in the box that opens and press Enter. He stays unlocked for that visit to the page. On this site the code is the one generated the first time Arcade Management is opened (shown once), or whichever you have set since on the Games page{% if not glob.hero_set %}; none exists yet, so open the Games page once to create it{% endif %}. Stand-in codes written in the project files never work on the live site. This guide is included in the downloads.
