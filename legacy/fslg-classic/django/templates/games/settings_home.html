How to use Arcade Management
  1. Games (this page): switch a game on or off, switch its cheats on or off, and press Edit for its rules, cheat codes and secret character.
  2. All cheat codes: every code for every game on one page, with search. Use the Download buttons for PDF, Word or Excel.
  3. Edit a code: open the game → Cheat codes tab → change the typed word or the dial code → Save. Untick “On” to disable one cheat.
  4. Who may cheat: set it for all games under “Settings for every game” below, or per game on its General tab.
  5. Secret character: the guide page explains the reveal move, where the code goes and his powers, per game.
  6. Give someone access to this section: Django admin → Users → the person → User permissions → add “Can open Game Settings”.
